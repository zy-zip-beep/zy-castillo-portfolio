ZY CASTILLO portfolio - GitHub Pages package

Upload everything inside this folder (index.html and the assets folder) to the ROOT of your GitHub repository.
Then: Settings > Pages > Deploy from a branch > main / (root) > Save.

Videos will not play when index.html is double-clicked (Chrome shows Error 153 for file:// pages).
They play correctly on GitHub Pages or via a local server (python -m http.server 8000, then open http://localhost:8000).
